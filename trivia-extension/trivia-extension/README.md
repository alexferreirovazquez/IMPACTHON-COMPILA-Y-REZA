# 🧠 BrainGate – Extensión de Chrome

Bloquea el acceso a redes sociales con preguntas de trivia.
- ✅ Si aciertas → entras
- ❌ Si fallas → esperas 60 segundos

## 📦 Instalación en Chrome

1. Descarga y descomprime el archivo ZIP
2. Abre Chrome y ve a: `chrome://extensions/`
3. Activa **"Modo desarrollador"** (esquina superior derecha)
4. Haz clic en **"Cargar descomprimida"**
5. Selecciona la carpeta `trivia-extension`
6. ¡Listo! Verás el icono 🧠 en tu barra de extensiones

## ⚙️ Configuración

Haz clic en el icono 🧠 para:
- Activar/desactivar la extensión
- Elegir qué sitios bloquear
- Ver estadísticas de aciertos/fallos

## 🌐 Sitios compatibles por defecto
- TikTok
- Instagram  
- Twitter / X
- Facebook
- YouTube
- Reddit

## 📝 Notas
- Funciona con Manifest V3 (Chrome moderno)
- Las preguntas son aleatorias de un banco de 25+
- El cooldown de 60s se guarda aunque cierres el navegador
