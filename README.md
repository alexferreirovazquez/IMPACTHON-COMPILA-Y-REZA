# IMPACTHON-COMPILA-Y-REZA
5 alumnos de 1º, 0 idea de qué estamos haciendo y una fe ciega en Ctrl+C y Ctrl+V 

La última versión es 'Luis3'

Para activar la extensión:
1. Usa un navegador que use el motor Chromium
2. Clickar en los 3 puntos
3. Buscar 'extensiones'
4. Activar el modo desarrollador (arriba a la derecha)
5. Pulsar 'cargar descomprimida' y subir una carpeta con todos los ficheros del repositorio

Para configurar las opciones, busca el icono de 'extensiones', a la derecha de la barra de navegacion, y en Focus Friends clicka en los 3 puntos, y selecciona 'opciones'. Ahí se podrá configurar el tiempo de bloqueo tras fallar una pregunta, el intervalo de tiempo en el que se repiten preguntas, qúe paginas se verán afectadas por la extensión y de qué categorías quieres que sean las preguntas.

Al entrar a una de esas webs, te preguntará de nuevo si quieres entrar, y si accedes, saltará una pregunta. Si aciertas, podrás utilizar la web hasta que aparezca otra pregunta en el intervalo de tiempo establecido. Si fallas, se bloquerá la pantalla

Consulta los puntos que tienes, así como los globales acumulados y los que tienen tus amigos con los que crees salas.
